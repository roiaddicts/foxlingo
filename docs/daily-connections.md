# Daily Football Connections

Sixteen source-listed players form four hidden groups of four. Easy filters to source categories marked `easy`; Normal uses the full category pool. Hard uses the same Normal puzzle, with a limit of five wrong checks. The separate replayable country game is labeled Practice Connections.

The compiler pins the source selector, binds the imported general player table and requires portraits. It shuffles with MM/DD/YYYY/, skips categories containing already-selected players and excludes full memberships of earlier chosen categories when selecting new players. This prevents a selected player from belonging to two selected groups. Original Normal `groups` and `order` remain for compatibility; additive `boards` include Easy and Normal. Independent authored JavaScript reads JSON data only and verifies both boards. Downloaded JavaScript is never executed.

The loader verifies date, table schemas, source category IDs/titles, Easy eligibility, sixteen distinct available portraits, positive membership and exclusivity against full category memberships. General IDs retain their namespace. Missing or ambiguous memberships never become negative football claims. Other real connections between the shown players may exist; guesses must match one of this daily puzzle’s four groups.

The phone board uses four equal portrait columns with selected borders. A correct group moves into a visual row with its source title and four faces. Flags and club artwork appear when the seed category ID and complete source title both match. This join supplies artwork only; it does not import old memberships or merge player identities. A wrong selection with three players from one selected group gets the source near-miss message. Wrong selections stay picked for editing or clearing. Repeating a wrong check consumes another mistake in Hard, matching the source. Easy and Normal allow unlimited mistakes and offer a confirmed reveal that finishes as a loss. Hard reveals automatically on the fifth error.

Difficulty preference, partial selection, found-group order, checks, errors and terminal outcomes save under the source signature. Found groups never reenter the selectable pool. Won rounds grant streak credit once, including recovery after interruption; losses and revealed groups do not. Mistake references are withheld from recommendations until the puzzle ends, avoiding hidden-group spoilers. They preserve source player identities without guessing canonical lesson subjects.

The current packet enables thirteen daily adapters. Fixed-date core and simulator fixtures verify all three modes, near misses, full wins, saved selected players, found-order recovery, five-error losses and confirmed reveal. A separate core test checks the current bundled packet so fixture stability does not force a stale release bundle.
