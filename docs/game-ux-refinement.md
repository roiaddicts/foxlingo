# Game interaction refinement

Visual thesis: Fox navy frames a compact training ground where faces, badges and real shirts dominate the board.

Content plan: Keep round progress small, show the playable board immediately, place clues next to visible choices, and pin player search above the keyboard. Match confirmation is a corner mark, never a second content row.

Interaction thesis: Fast flips can be interrupted; timeline milestones can be lifted and dropped; the streak uses advected procedural noise rendered by Metal, with greater heat and height at longer streaks.

Remaining product work: inventory every Futbol11 football mechanic and variant, implement the missing games, record missed relationships, recommend sourced lessons, and connect optional generated lessons through a server endpoint with credentials kept off device. Full catalog coverage remains in progress.

Implemented: larger/cropped faces, corner match marks, uniform lineup cards with 98 cached season shirts, keyboard-adjacent search, interruptible flips, inline mystery choices and primary clues, native timeline drag and procedural Metal fire. Mistake-driven sourced recommendations persist across launches and avoid mystery spoilers. Football Wordle is the first added source mode; other catalog modes remain planned.
