# Authoring football timelines

`content/timeline-rounds.json` defines the bundled timelines; `scripts/build_content.py` copies it to `Foxlingo/Resources/timeline-en.json`. Each board has a stable string `id`, canonical club `subjectID`, a date-free title, and three to six events. Each event has a stable string `id`, a date-free title and canonical `factID`. The milestone caption must describe what that fact actually supports. Review captions against the fact's cited source before publishing.

Chronology derives from numeric facts with unit `year`, or literal dates encoded as strict `YYYY-MM-DD`. The game does not manufacture a month/day for a year-only fact. Milestones must have distinct years: finer ordering within the same year is deliberately rejected until interval/tie semantics are supported. Facts and event IDs must be distinct; repeated captions are rejected. Club/player subjects need cached artwork, and dates must not appear in titles. Sources, scopes and dated evidence appear only after solving or explicitly revealing the story.

A club milestone must belong to the board's club. A player milestone requires a supported history relationship to that club and explicit club context in the dated fact's own evidence/scope. General career dates cannot automatically become milestones for every club the player represented. Current examples reuse Casillas's Real Madrid debut and the favorite clubs' founding, promotion and European/Liga MX championship facts. New captions are teaching material, not new factual evidence.

Saved boards fingerprint event captions, references, date values and scopes. Semantic changes retire an incompatible board; artwork/source-title updates and event-array reordering preserve it. Removing a referenced club/fact keeps the unaffected rounds available and shows a content notice. Malformed definitions fail validation. Event order, move/check counts and the original session ID persist after every change. Finishing removes the draft and records activity in one learner-state save; repeating that session ID cannot award activity again. Neither correct nor assisted timelines change recall schedules or album tiers.

Timeline definitions currently ship with the app; the lesson-only content feed does not deliver new game mechanics or timeline definition files. Incoming curricula can affect the facts these boards reference, so compatibility is checked on launch.
