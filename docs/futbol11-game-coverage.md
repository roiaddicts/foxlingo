# Futbol11 game coverage

The current source lists 19 football modes. `content/futbol11-game-catalog.json` records each mode, its rule reference, required data and implementation status. Eighteen of nineteen modes currently reproduce their core source mechanic: Grid, Bingo, Football Wordle, Connections, Impostor, Nations XI, Clubs XI, Retro XI, Legends XI, America XI, Top 10, Statdle, Legacy, Link, Pyramid, SquadSlice, Guess the Footballer and Goltexto. Connections and Impostor currently use four explicit country categories, with cached portraits preferred. They exclude players classified into multiple countries within the chosen board so groups have a unique solution. Club and achievement variants remain to be authored; missing club membership is never used as a negative career claim. The existing single-squad lineup, Who am I?, Memory and Timeline are separate Foxlingo games.

The native Retro game draws one historical season squad per distinct club and mixes eleven offers into an XI. Nations, Legends, America and Clubs use separate eligibility pools. America is a South American club game, not a nationalities game. See `docs/xi-drafting.md` for source identities, solver rules and scope. Statdle requires season-specific values; lifetime records are not substitutes. Link requires evidence of sharing senior appearances; co-membership in a seasonal squad alone is insufficient. Similarity games must explain the compared traits and never adjudicate factual free-text answers by similarity alone.

Missing modes remain planned until playable natively and verified. The JSON catalog is development tracking, not a claim that these games are available in the app. Current source data describes different cutoff dates per mode; preserve those scopes rather than presenting it as live 2026 statistics.

Mistake tracking now stores up to 500 practice gaps independently of recall, album mastery and streaks. Available source-backed lessons are recommended by exact fact first, then related subject. Unknown seed records retain the original reference names, namespaced player IDs and visual asset IDs in practice gaps, even when no canonical learning subject matches. They do not produce invented recommendations. Mystery gaps stay in the saved round until identification so lesson titles cannot reveal a hidden answer. Wordle uses normalized first names, surnames and nicknames with four to eight letters and consumes repeated-letter counts correctly; finished losses reveal the answer but do not advance a streak.

On-demand generation still needs a configured server and verified evidence; provider credentials belong on the server.

Daily extraction now covers all nineteen source modes through `refresh_daily_futbol11.py`, with explicit dates/timezones, reviewed selector contracts, retries and atomic last-good publication. See `docs/futbol11-daily-data.md`. Extraction coverage does not count as native game coverage, and Top 10, Statdle, Legacy, Link, Pyramid, SquadSlice, Guess the Footballer and Goltexto now consume these packages in-app through a bundled offline set, verified HTTPS pointer feed, and JSON import. The other native games still need daily adapters.

Statdle preserves its exact season, competition, appearances, goals, assists, age, valuation, position, club and nationality. It provides five chances; misses and skips reveal two randomly chosen remaining clues. Hard mode locks club and nationality. Legacy reveals one of four source-listed club shirts per miss/skip, in the source-shuffled order. Link reveals one of five explicitly authored senior teammates per miss/skip, with player portraits. These three daily modes persist clue order, difficulty, attempts, wins and losses. Completed wins grant streak credit once; losses reveal the answer without credit. Practice-gap recommendations wait until the mystery ends to avoid spoilers. See `docs/daily-player-clues.md`.

Pyramid ranks ten source-selected players in exact descending order across four visual rows, with draggable portraits, tap swaps, Easy rank bands and one check that locks correct positions. SquadSlice uses a season-specific nationality ring, flags and source club shirts with three chances. Both save progress and grant completed-win credit once. See `docs/daily-visual-boards.md`.

Guess the Footballer is the source yes/no deduction game, distinct from Foxlingo’s authored Who am I? clues. It supports ten questions and three guesses, with current-snapshot and listed-career club/league topics, nationality, position, age and height. See `docs/daily-guess-the-footballer.md`.

Goltexto compares catalog club, rating, age, positions, source league/region groups and nationality with the exact source weights. It offers 10, 20 or 100 guesses, signed scores, visual search profiles, an expandable breakdown and saved rounds. Only the exact source identity wins; partial similarity does not grade factual recall. See `docs/daily-goltexto.md`. Bingo Retro is the remaining native mode.
