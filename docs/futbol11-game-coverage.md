# Futbol11 game coverage

The current source lists 19 football modes. `content/futbol11-game-catalog.json` records each mode, its rule reference, required data and implementation status. Ten of nineteen modes currently reproduce their core source mechanic: Grid, Bingo, Football Wordle, Connections, Impostor, Nations XI, Clubs XI, Retro XI, Legends XI and America XI. Connections and Impostor currently use four explicit country categories, with cached portraits preferred. They exclude players classified into multiple countries within the chosen board so groups have a unique solution. Club and achievement variants remain to be authored; missing club membership is never used as a negative career claim. The existing single-squad lineup, Who am I?, Memory and Timeline are separate Foxlingo games.

The native Retro game draws one historical season squad per distinct club and mixes eleven offers into an XI. Nations, Legends, America and Clubs use separate eligibility pools. America is a South American club game, not a nationalities game. See `docs/xi-drafting.md` for source identities, solver rules and scope. Statdle requires season-specific values; lifetime records are not substitutes. Link requires evidence of sharing senior appearances; co-membership in a seasonal squad alone is insufficient. Similarity games must explain the compared traits and never adjudicate factual free-text answers by similarity alone.

Missing modes remain planned until playable natively and verified. The JSON catalog is development tracking, not a claim that these games are available in the app. Current source data describes different cutoff dates per mode; preserve those scopes rather than presenting it as live 2026 statistics.

Mistake tracking now stores up to 500 practice gaps independently of recall, album mastery and streaks. Available source-backed lessons are recommended by exact fact first, then related subject. Unknown seed records retain the original reference names, namespaced player IDs and visual asset IDs in practice gaps, even when no canonical learning subject matches. They do not produce invented recommendations. Mystery gaps stay in the saved round until identification so lesson titles cannot reveal a hidden answer. Wordle uses normalized first names, surnames and nicknames with four to eight letters and consumes repeated-letter counts correctly; finished losses reveal the answer but do not advance a streak.

On-demand generation still needs a configured server and verified evidence; provider credentials belong on the server.
