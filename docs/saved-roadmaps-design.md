# My roadmaps design

Visual thesis: saved subjects form a small illustrated reading list within the existing Fox navy learning journal.

Content plan: keep Learn focused on the selected subject and daily plan. Put My roadmaps at the top of the chooser, with each badge/portrait, name and required progress. Browsing filters apply to the catalog, while saved subjects span clubs, players and competitions. An explicit bookmark control saves or removes a path without selecting it.

Interaction thesis: bookmark state changes use a short fade, existing press feedback and local haptics; the selected path retains its checkmark. Motion respects Reduce Motion. Each selection and bookmark control has its own accessible tap target. Saved rows precede the stable browsing catalog, and searching shows a single set of catalog results.

Adversarial requirements: migrate legacy saves to Xolos/Madrid defaults once; preserve explicit empty collections and ordered IDs; keep unavailable saved IDs for restored packs. Removing a selected path leaves it selected and keeps learning history. Daily recommendations prioritize selected-path work, then required work from saved paths in saved order; do not let unrelated unsaved interruptions hijack the plan. Carry the recommending roadmap ID so shared lessons name their actual recommendation context. Due recall remains global.
